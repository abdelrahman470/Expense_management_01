# 💰 إدارة المصاريف الشهرية

موقع ويب متطور لإدارة المصاريف الشهرية مع تصميم داكن أنيق وواجهة سهلة الاستخدام.

## ✨ الميزات الرئيسية

### 📊 لوحة التحكم
- **ملخص سريع**: عرض إجمالي الدخل والمصروفات والرصيد المتبقي
- **رسوم بيانية تفاعلية**: مخططات شهرية وتوزيع المصروفات حسب الفئات
- **إحصائيات مفصلة**: تحليل شامل للإنفاق والدخل

### 💳 إدارة العمليات
- **إضافة عمليات**: دخل ومصروفات مع تفاصيل كاملة
- **تعديل وحذف**: إمكانية تعديل أو حذف أي عملية بسهولة
- **تصنيف ذكي**: فئات متنوعة (طعام، مواصلات، فواتير، إلخ)
- **ملاحظات**: إضافة ملاحظات لكل عملية

### 🔍 البحث والفلترة
- **بحث متقدم**: البحث في الفئات والملاحظات
- **فلترة ذكية**: حسب النوع والفئة والتاريخ
- **ترتيب مرن**: ترتيب حسب أي عمود
- **عرض ديناميكي**: تحديث فوري للنتائج

### 💾 حفظ البيانات
- **حفظ محلي**: استخدام localStorage لحفظ البيانات
- **تصدير البيانات**: إمكانية تصدير البيانات كملف JSON
- **استيراد**: إمكانية استيراد البيانات المحفوظة
- **نسخ احتياطي**: حماية البيانات من الفقدان

## 🎨 التصميم

### 🌙 الوضع الداكن
- **ألوان متناسقة**: تدرجات داكنة مائلة للأخضر المزرق
- **تباين ممتاز**: نصوص واضحة على خلفيات داكنة
- **أيقونات جميلة**: استخدام Font Awesome للأيقونات
- **خطوط عصرية**: خط Poppins للوضوح والجمال

### 📱 تصميم متجاوب
- **متوافق مع الموبايل**: يعمل على جميع الأجهزة
- **تخطيط مرن**: يتكيف مع أحجام الشاشات المختلفة
- **تفاعل سلس**: تأثيرات حركية ناعمة
- **سهولة الاستخدام**: واجهة بديهية ومفهومة

## 🛠️ التقنيات المستخدمة

- **HTML5**: هيكل الصفحات
- **CSS3**: التصميم والتنسيق
- **Bootstrap 5**: إطار العمل للتصميم المتجاوب
- **JavaScript ES6+**: البرمجة والتفاعل
- **Chart.js**: الرسوم البيانية التفاعلية
- **SweetAlert2**: التنبيهات الجميلة
- **Font Awesome**: الأيقونات
- **localStorage**: حفظ البيانات محليًا

## 🚀 كيفية الاستخدام

### 1. فتح الموقع
- افتح ملف `index.html` في المتصفح
- الموقع يعمل بدون حاجة لخادم ويب

### 2. إضافة عملية جديدة
- اضغط على "إضافة عملية" في القائمة
- اختر نوع العملية (دخل أو مصروف)
- حدد الفئة والمبلغ والتاريخ
- أضف ملاحظات إذا أردت
- اضغط "حفظ"

### 3. إدارة العمليات
- عرض جميع العمليات في الجدول
- استخدام البحث والفلترة للعثور على عمليات محددة
- تعديل أو حذف العمليات باستخدام الأزرار
- ترتيب الجدول بالنقر على رؤوس الأعمدة

### 4. عرض الإحصائيات
- مراقبة الملخص المالي في الأعلى
- تحليل الرسوم البيانية للاتجاهات
- تتبع توزيع المصروفات حسب الفئات

## 🔧 التخصيص

### تغيير الألوان
يمكن تعديل الألوان في ملف `styles.css` من خلال متغيرات CSS:

```css
:root {
    --primary-bg: #0f1a17;      /* الخلفية الرئيسية */
    --secondary-bg: #1b3a36;   /* الخلفية الثانوية */
    --accent-color: #4fd1c5;   /* اللون المميز */
    --text-primary: #e0e0e0;   /* النص الرئيسي */
}
```

### إضافة فئات جديدة
يمكن إضافة فئات جديدة في ملف `script.js`:

```javascript
// في دالة getCategoryIcon
const icons = {
    'طعام': 'utensils',
    'مواصلات': 'car',
    'فواتير': 'file-invoice',
    // أضف فئات جديدة هنا
    'فئة جديدة': 'icon-name'
};
```

## 📊 الميزات المتقدمة

### الرسوم البيانية
- **مخطط خطي**: تتبع الدخل والمصروفات عبر الأشهر
- **مخطط دائري**: توزيع المصروفات حسب الفئات
- **تحديث تلقائي**: الرسوم تتحدث مع كل تغيير

### البحث والفلترة
- **بحث فوري**: النتائج تظهر أثناء الكتابة
- **فلترة متعددة**: حسب النوع والفئة والتاريخ
- **ترتيب مرن**: ترتيب تصاعدي أو تنازلي

### حفظ البيانات
- **حفظ تلقائي**: البيانات تحفظ مع كل تغيير
- **تصدير آمن**: إمكانية تصدير البيانات
- **استيراد سهل**: استعادة البيانات المحفوظة

## 🎯 نصائح للاستخدام

1. **أدخل البيانات بانتظام**: سجل كل عملية فور حدوثها
2. **استخدم الفئات بدقة**: هذا يساعد في التحليل
3. **راجع الإحصائيات**: تابع الإنفاق شهريًا
4. **احتفظ بنسخة احتياطية**: صدر البيانات بانتظام
5. **استخدم الملاحظات**: أضف تفاصيل إضافية للعمليات

## 🔒 الأمان والخصوصية

- **بيانات محلية**: جميع البيانات محفوظة في المتصفح فقط
- **لا توجد خوادم**: لا يتم إرسال البيانات لأي خادم خارجي
- **خصوصية كاملة**: بياناتك تبقى على جهازك فقط

## 🆘 الدعم والمساعدة

إذا واجهت أي مشاكل أو لديك اقتراحات:

1. تأكد من أن المتصفح يدعم JavaScript
2. تحقق من إعدادات localStorage
3. جرب تحديث الصفحة
4. تأكد من اتصال الإنترنت (لتحميل المكتبات)
